# Catho Tours International

Site officiel de Catho Tours International (React 19, TypeScript, Vite, Tailwind CSS).

## Démarrage

```
cd client
npm install
npm run dev
```

Le site est alors disponible sur http://localhost:5173.

## Commandes

- `npm run dev` : serveur de développement
- `npm run build` : compilation de production (dossier `client/dist`)
- `npm run lint` : analyse du code
